文件为单一组件 `Home`，内部按视觉层次拆分为多个独立子组件：
- 3D 场景层：`BlackHoleCore`（黑球）、`PhotonRing`（内/外双层 torus + shaderMaterial）、`AccretionDisk`（18000 点粒子 + 自定义顶点/片元着色器实现开普勒旋转与湍流）、`PlasmaStreams`/`PlasmaLine`（螺旋流线）、`DustFilaments`（5000 细颗粒）、`OuterGlow`（BackSide 球体 rim-light）、`GravitationalLensing`（带星空背景的扭曲平面），全部由 `SceneContent` 组合并通过 `<Canvas>` 挂载。
- UI 覆盖层：绝对定位的 flex 容器，包含居中标题区（随鼠标视差位移）、底部 About/Projects/Contact 按钮（通过 `document.getElementById(...).scrollIntoView` 平滑滚动到锚点）、右侧圆形导航点。
- 依赖方向：仅向上依赖 `@react-three/fiber`、`@react-three/drei`、`three`；无跨模块引用，自身即最终导出默认组件。
