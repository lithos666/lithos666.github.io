模块由三个文件构成应用的最外层边界：
- `src/main.jsx` 作为 Vite/ReactDOM 的入口，通过 `createRoot` 将 `<App />` 渲染到 `#root`，并包裹在 `<StrictMode>` 中。
- `src/App.jsx` 是顶层页面容器，负责组合全局 UI 组件（`SmoothScroll`、`CustomCursor`）、滚动进度条（基于 `framer-motion` 的 `useScroll` + `useSpring`）和固定导航栏；首屏的 `HeroSection`、`WorksSection` 直接同步 import，其余长列表/重组件（YearOne/Two/ThreeProjects、AboutSection、KnowledgeBase、ContactSection）使用 `React.lazy` + `Suspense` 懒加载，并以统一的 `SectionSkeleton` 占位，实现按滚动分块加载的首屏优化策略。
- `src/constants.js` 作为纯数据层，以命名空间对象（`COVER_FLOW`、`CARD_STYLE`、`NAVBAR`、`CURSOR`、`VALIDATION`）导出所有魔法数字与动画参数，供各子组件按需引用，避免硬编码散落。
依赖方向单向向下：`main.jsx → App.jsx → components/*`，`constants.js` 被上层多处消费但不反向依赖任何组件。
