- 每个 3D 子组件内部用 useRef 持有 mesh/points/line 引用，并通过 useFrame 在每帧更新 geometry.attributes.position.needsUpdate 或 material.uniforms.time.value。
- 大规模静态数据（粒子位置、颜色、速度等）统一在 useMemo 中生成 Float32Array，并以 count/radius 等作为依赖键避免重复计算。
- 发光/半透明材质一律同时设置 transparent、depthWrite={false} 与 blending={THREE.AdditiveBlending}，以保证多层叠加时的正确混合。
- UI 交互采用内联 style + onMouseEnter/onMouseLeave 直接修改 e.currentTarget.style 的方式实现 hover 动效，而非外部 CSS 类切换。
